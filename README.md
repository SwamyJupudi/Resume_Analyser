# FitLens

An AI-powered Resume Analyser that helps job seekers understand how well their resume matches a job description.

The application analyses a resume, compares its skills with the requirements of a job description, identifies missing skills, calculates a match score, and provides AI-powered suggestions for improvement.

## 🚀 Features

- 🔐 User Registration & Login
- 🔑 JWT-based Authentication
- 📄 Resume Upload and Text Extraction
- 💼 Job Description Analysis
- 🎯 Resume-to-Job Skill Matching
- 📊 Resume Match Score
- ❌ Missing Skills Detection
- 💡 Resume Improvement Suggestions
- 🤖 AI-powered Resume Analysis
- 📜 Analysis History
- 🗑️ Delete Previous Analyses
- 🌐 Responsive React Frontend
- 🔒 Protected API Endpoints
